# Nova ERP Dashboard

Dashboard de ERP multinegocio orientado a visualizar ventas, inventario, compras, rentabilidad y comisiones en un solo lugar.

[Ver demo en vivo](https://alejandroinsfran.dev/demos/erp/) · [Portafolio](https://alejandroinsfran.dev/)

## Qué resuelve

Centraliza los indicadores operativos que normalmente están dispersos entre ventas, inventario y administración. La demo prioriza una lectura rápida de métricas y acciones frecuentes del negocio.

## Funcionalidades

- Dashboard con ventas netas, utilidad bruta, stock bajo y comisiones.
- Módulo de ventas con pedidos, canales y registro de nuevas ventas.
- Módulo de inventario con existencias críticas y acción de reposición.
- Módulo de compras con órdenes y proveedores.
- Módulo de comisiones con liquidaciones por vendedor.
- Interacciones demo: registro de ventas, creación de órdenes y conciliación de acciones.

## Stack utilizado

- Next.js 15 con App Router
- React 19
- TypeScript en modo estricto
- Tailwind CSS

## Alcance técnico

Los datos visibles en la demo son simulados y se mantienen en el cliente para mostrar el flujo de la interfaz sin exponer información comercial. El proyecto está preparado para conectarse a una API y una base de datos en una siguiente etapa, manteniendo separada la lógica de presentación de las fuentes de datos.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).
